# English Practice Agent

A conversational English-practice agent built with [Google ADK](https://google.github.io/adk-docs/) (Python).

The agent chats with the user in English, adapting its vocabulary and sentence
complexity to the user's demonstrated level. At the end of every reply, it
gently corrects exactly one mistake from the user's last message (grammar,
word choice, or phrasing) — the single most useful one. If there are no
mistakes, it says nothing about corrections. The correction is short,
encouraging, and clearly separated from the conversational part of the reply.
